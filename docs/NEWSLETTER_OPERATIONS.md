# Optional newsletter signup

Disabled by default. The founder selects Buttondown or MailerLite in Site Settings and configures NEWSLETTER_API_KEY. A published/approved Privacy page in the page language is required before the footer form appears. Both providers receive pending/unactivated subscription requests; existing opted-out addresses are not explicitly activated. The form uses consent and verified Turnstile.

Provider reference: [Buttondown subscriber creation](https://docs.buttondown.com/api-subscribers-create), [MailerLite subscriber API](https://developers.mailerlite.com/api/subscribers). For MailerLite, configure and verify the account's API double-opt-in behavior before launch. Live signup and confirmation delivery are UNVERIFIED.
