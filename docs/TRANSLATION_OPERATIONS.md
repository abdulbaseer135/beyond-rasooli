# Translation operations

Authenticated same-origin generation creates or updates an actual independent Draft/machine_draft article or video, preserving translationGroup, provenance, structural rich text, SEO, transcript, captions, evidence, corrections and explanatory source notes. Reviewed overwrite requires explicit confirmation. Native review and subsequent publication remain separate. Provider failures never return mock translations.

Set ANTHROPIC_API_KEY, a currently valid ANTHROPIC_MODEL, verified input/output prices per million tokens, CMS glossary and translationBudgetUsd. Usage and conservative reservations persist without manuscript text. A unique active reservation serializes calls across workers; interrupted requests fail closed until the founder inspects/deletes the abandoned active reservation in Translation Usage.

The side-by-side tool persists title/summary or description edits and review status. Rich-text/transcript editing uses the linked native Payload record. Source edits flag reviewed translations; completing review clears the flag.

Live provider generation, pricing accuracy, production concurrency, translation quality and automatic generation on publish are UNVERIFIED. Current source cap is 20,000 characters and provider output cap 4,000 tokens. Incomplete/malformed structural output is rejected; long manuscripts require a reviewed chunking strategy rather than partial publication. Configure and test staging before enabling this P1 workflow for real content.
